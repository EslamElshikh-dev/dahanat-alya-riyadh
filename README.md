# دهانات عليا

موقع عربي متجاوب لخدمات الدهانات والتشطيبات والديكورات في مدينة الرياض.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

## البناء

```bash
pnpm build
```

بيانات النشاط وأرقام التواصل موجودة في `data/site.ts`، ومحتوى صفحات الخدمات في `data/services.ts`.

## قياس التواصل من الموقع

`components/google-ads-tracking.tsx` يحمّل علامة Google Ads بعد تحميل واجهة الموقع، على نطاق الإنتاج الرئيسي فقط. قياس ضغط الهاتف وفتح واتساب منفصلان في `lib/contact-tracking.ts`؛ لا يُرسل حدث تحويل عند زيارة الصفحة، ولا تُرسل الرسالة أو تفاصيل الطلب ضمن معلمات الحدث. تظل روابط التواصل تعمل بطريقتها الأصلية حتى عند تعذّر تحميل Google.

إجراءا الموقع في Google Ads ثانويان للملاحظة، بعدّ واحد وبدون قيمة مالية. يظهران في «كل الإحالات الناجحة»، ولا يمثلان مكالمة مكتملة أو رسالة مُرسلة أو عملية بيع. لا تغيّر أصل الاتصال أو أهداف المكالمات الحالية في الإعلان عند صيانة هذا الربط.

```bash
node --import tsx --test tests/contact-tracking.test.ts
```

بعد تغيير معرّفات القياس، راجع مقتطفَي الحدث في Google Ads، ثم اختبر الهاتف وواتساب من صفحة منتج عبر Tag Assistant. يجب أن يصدر حدث واحد للقناة الصحيحة عند الضغط، وأن تبقى أرقام وروابط الاتصال كما هي. المعاينات والتشغيل المحلي لا يرسلان تحويلات إلى الحساب الحي.
